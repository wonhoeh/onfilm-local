공개본 만들기

읽기 전용 포트폴리오

저장된 프로필·사진·필모그래피와 HLS 영상을 별도 파일로 복사합니다. 온라인에는 아직 게시되지 않습니다.

DB, 원본 영상, 작업 기록은 포함하지 않습니다. 연결된 영상은 모두 인코딩을 완료해 주세요. 복사할 영상만큼 추가 저장 공간이 필요합니다.

이메일을 표시하지 않으려면 프로필 편집에서 비워 저장해 주세요. 이전 공개본·ZIP·게시된 사이트에서는 자동 삭제되지 않습니다. 전화번호는 새 공개본에 포함하지 않습니다.

저장된 공개본을 확인하고 있습니다.

앱 저장 공간

파일 크기의 합계이며 작업 중에는 달라질 수 있습니다. 외부 백업·복원 전 보관 폴더·외부에 저장한 ZIP·휴지통 사용량은 포함하지 않습니다. 휴지통을 비워야 실제 여유 공간이 늘어납니다.

공개본은 만든 시점의 복사본입니다. ZIP 저장으로 보관하거나 결과 폴더를 열 수 있습니다. 로컬 수정 후 다시 만들면 새 공개본이 추가됩니다. 정리는 확인 후 선택한 공개본만 휴지통으로 이동합니다. DB·원본 영상·백업·외부 ZIP·게시된 사이트는 변경하지 않습니다. 실패 부분 파일 정리·온라인 게시는 후속 단계입니다.
