게시와 저장 공간 안내

선택한 공개본으로 연결된 Pages 프로젝트 전체를 교체합니다. 사진·재생용 영상은 R2에 저장되며, 원본 영상과 DB는 업로드하지 않습니다.

수정 후에는 새 공개본을 만들어 게시하세요. 게시 성공 후 앱이 기록한 이전 R2 전용 경로는 정리합니다. 게시 종료는 종료 화면 배포·과거 Pages 배포 삭제·전용 R2 버킷 공개 차단을 수행합니다. 로컬 데이터와 R2 파일은 유지되며 저장 용량도 남습니다. 종료에는 Cloudflare 연결의 R2 관리 API Token이 필요합니다.
