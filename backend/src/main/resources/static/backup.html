데이터 백업·복원

프로필·사진·작품·이메일·원본 영상·인코딩 결과를 함께 보관합니다. 공개본 ZIP과 다르며, 백업 폴더 전체를 보관해야 합니다.

인코딩과 대기 작업이 끝난 뒤 실행해 주세요. 작업 중 로컬 서버를 잠시 종료하고 완료 후 다시 시작합니다. 완료 전 앱이나 PC를 종료하지 마세요.

공개본·ZIP·로그는 제외합니다. 백업은 암호화되지 않으므로 다른 사람에게 공유하거나 공개 호스팅에 올리지 마세요. 직접 만든 신뢰할 수 있는 백업만 복원하세요.

복원 전 데이터와 실패한 임시 파일은 안전을 위해 자동 삭제하지 않습니다. 추가 저장 공간이 필요합니다.
