# 004. 원본 OnFilm 프로필 페이지 구성을 유지

사용자 요청: 로컬 실행만 다르고 화면 구성은 원래 OnFilm과 동일하게. 랜딩페이지는 만들지 않는다.

## 그대로 가져온 부분

- `actor-detail.html`의 프로필 사진/정보 좌우 배치, SNS 아이콘, PROFILE TAGS.
- FILMOGRAPHY와 PHOTO 섹션 순서, 원형 SVG 아이콘·설명·첫 게시물 등록 링크.
- 톱니바퀴 버튼과 편집 메뉴(프로필/필모그래피/사진 갤러리/닫기).
- 원본 `common.css`, `actor-detail.css`, 기본 프로필 이미지.
- 사진 3열 그리드·4:5 썸네일 및 확대 화면 스타일.

임시 카드형 프로필 박스, SNS 주소 입력칸, 별도 PHOTO 관리 버튼, 항상 보이는 로컬 안내 문구는 제거했다. 초기 프로필 입력은 사진/필모그래피 없이 그대로 유지한다.

## 로컬에서 달라지는 동작 / 미구현

- 소유자 화면만 사용하므로 로그인/로그아웃 UI와 계정 조회는 제외.
- 이름이 없으면 입력, 있으면 프로필 조회로 진입. 랜딩페이지 없음.
- 사진 빈 상태의 첫 사진 등록 및 설정 메뉴의 갤러리 편집은 로컬 편집 화면으로 연결.
- 필모그래피 버튼은 원본과 같은 모양/문구지만 등록·저장 기능은 아직 없다. 클릭 시 명확한 미연결 안내를 표시하며 성공이나 데이터 저장을 흉내 내지 않는다.
- SNS는 기존 아이콘 모양으로 표시하되 외부 앱 실행 권한을 추가하지 않았다. 클릭하면 주소 선택/복사 안내. 외부 브라우저 자동 열기는 후속 작업.
- 사진 조회 실패는 빈 갤러리로 위장하지 않고 재시도 제공. 확대 시 이전/다음/Escape/닫기 지원.

## 오프라인 자산

원본 CSS가 CDN에서 참조하던 Instagram/YouTube/TikTok/링크 SVG를 `static/icons`에 포함했다. Simple Icons 및 Bootstrap Icons의 라이선스도 동봉했다. 로컬 CSS에서 mask URL만 로컬 파일로 덮어쓴다. 따라서 프로필을 열 때 CDN 스크립트나 폰트·아이콘 다운로드는 필요 없다. 원본의 HLS CDN 스크립트는 아직 영상 기능이 없으므로 포함하지 않는다.

DB 스키마 변경 없음. 기존 사진·SNS·태그·갤러리 데이터는 보존한다.
