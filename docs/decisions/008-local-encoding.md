# 단일 로컬 HLS 인코딩 (2026-09-28)

## 범위와 실행

저장된 영상에서 인코딩 시작을 누르면 V8 `encode_job`에 작업을 저장한다. 기존 Kafka/Worker 서버를 가져오지 않는다. Spring의 전용 예약 작업이 DB 대기 작업을 한 개씩 실행한다. HTTP 접수는 짧게 끝나고 FFmpeg 실행 중에는 DB 트랜잭션을 열어 두지 않는다.

- `POST /api/videos/{videoId}/encoding`: 연결된 원본의 작업 생성/실패 재시도. video_id UNIQUE이며 진행/완료 작업에 반복 요청해도 새 작업을 만들지 않는다.
- `GET /api/encoding`: 상태 조회. 편집 화면에서 2초마다 확인하되 폼을 다시 만들거나 미저장 입력을 덮어쓰지 않는다.
- 상태: QUEUED → RUNNING → DONE / FAILED. 종료 시 RUNNING → INTERRUPTED. 강제 종료 흔적도 다음 시작 때 INTERRUPTED로 변경한다.
- QUEUED는 재시작 후 실행한다. FAILED/INTERRUPTED는 사용자가 재시도한다. 중간 프레임 이어받기는 아니며 새 attempt 폴더에서 처음부터 변환한다.
- 작업은 작품이 아니라 불변 원본 video_id에 묶인다. 교체한 영상은 새 ID이므로 이전 작업 결과가 새 영상에 적용되지 않는다. 실행 직전 연결이 해제됐으면 실패 처리한다. 실행 중 연결 해제되면 기존 원본의 결과는 남을 수 있으나 현재 작품에 표시하지 않는다.

## 미디어 처리

- ffprobe로 영상 트랙·폭/높이·길이 확인. 유효한 길이 6시간 이하·4천만 화소 이하로 제한한다. probe는 30초, 변환은 최대 6시간 타임아웃이다.
- FFmpeg H.264/AAC, 최대 1280×720(비율 유지), 4초 간격 키프레임/HLS VOD. 단일 화질이며 멀티 비트레이트 스트리밍은 아니다. 무음 영상도 허용한다.
- 디코딩/인코딩 스레드 2, 필터 스레드 1. CPU 사용률 자체를 일정 비율 이하로 보장하지는 않는다.
- 출력: `data/media/encoded/{jobId}/attempt-{번호}/index.m3u8` 및 segment-*.ts. 완료 후 ENDLIST와 로컬 세그먼트 존재/크기를 확인한 뒤 DONE 처리한다.
- Java ProcessBuilder 인자 배열 사용, 셸 미사용. 프로토콜은 file/pipe, 외부 트랙 참조 비활성. 출력 진단은 128KiB까지만 보관하며 계속 읽어 파이프 교착을 막는다. UI에 원시 FFmpeg 로그/사용자 경로를 노출하지 않는다.
- 종료 시 직접 시작한 프로세스만 종료한다. 앱 강제 종료/전원 차단/OS별 자식 프로세스 잔류는 완전히 보장하지 않는다. 다음 실행은 미완료 작업을 완료로 처리하지 않는다.
- 원본은 보존한다. 실패한 시도의 결과도 자동 삭제하지 않는다. 저장 공간 사전 검사는 보조 수단이며 실행 중 디스크 부족은 실패로 처리한다. 정리 UI는 후속 작업이다.

## 개발 환경

현재 개발 PC의 FFmpeg/ffprobe 실행 파일을 사용한다. PATH 또는 `ONFILM_FFMPEG`, `ONFILM_FFPROBE`로 지정한다. renderer가 실행 파일 경로를 지정할 수 없다. Windows용 실행 파일 동봉·라이선스 검토·설치 패키징은 아직 하지 않았다.

실행 중 JAR 덮어쓰기를 피하도록 `./gradlew -PverificationBuild check bootJar`는 build-verification으로 분리한다. E2E에는 ONFILM_TEST_JAR로 이 JAR를 지정한다. 일반 개발 앱을 최신화할 때는 앱을 완전히 종료하고 일반 bootJar 빌드 후 다시 켠다.

## 남은 범위

이번 단계는 변환·상태·실패 재시도까지다. HLS HTTP 제공·재생 화면은 후속 `009-local-playback.md`에서 구현한다. 완료 알림, 세부 진행률, 작업 취소, 파일 정리, Windows 번들링은 남아 있다.

## 검증

- 임시 파일 H2: 중복 요청·실제 짧은 영상 HLS 생성·원본 보존·재시작 후 DONE 유지·실패 재시도·대기 유지·중단 상태·실행 파일 없음·잘못된 결과 경로 거부.
- 테스트는 설치된 FFmpeg를 사용한다. 미설치 시 실제 변환 테스트는 건너뛰며 설치 오류 안내는 별도 테스트한다.
- GUI E2E는 별도 검증 JAR와 임시 DB를 사용한다. Windows·장시간/고해상도 영상·실제 전원 차단은 미검증이다.
