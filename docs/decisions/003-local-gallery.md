# 003. 제한된 로컬 갤러리

사진 최대 12장. 각 JPEG/PNG 5MiB 이하이며 대표 사진과 동일한 자동 축소·PNG 재인코딩 처리를 재사용한다. 초기 800만 화소 제한은 폐기했다(`005-image-auto-resize.md`). 원본 파일명·경로·메타데이터를 저장하지 않으며 원본 파일을 삭제하거나 이동하지 않는다. EXIF 회전 보정은 아직 없다.

이번 MVP에서는 제한된 갤러리도 H2 BLOB으로 저장한다. 별도 파일 정리 큐 없이 사진 추가·삭제·정렬 정보를 동일 DB 트랜잭션으로 확정하기 위한 선택이다. PNG 변환 후 용량은 원본보다 커질 수 있으며 DB 파일 크기가 삭제 직후 줄어드는 것을 보장하지 않는다. 많은 사진·영상에는 이 방식을 그대로 확장하지 않는다. 별도 파일 저장소 전환과 백업·압축은 추후 검토한다.

프로필과 별도의 gallery_state.version을 사용한다. 모든 변경은 version 조건 UPDATE로 상태 행을 먼저 확보하므로 같은 버전을 보낸 변경은 하나만 성공한다. 정렬 API는 현재 ID 전체를 중복·누락 없이 보내야 한다. 개수 제한이나 잘못된 정렬·없는 사진 삭제로 실패하면 version 변경도 롤백된다.

여러 파일 선택은 한 장씩 순차 저장한다. 전체 배치를 원자적으로 취급하지 않는다. 중간 실패 시 완료한 사진은 유지하고 남은 업로드는 중단한다. 화면에 완료가 확인된 수를 표시하고 응답 유실로 결과가 불확실한 경우 다시 읽기를 안내한다. 자동 재시도로 중복 사진을 추가하지 않는다.

사진 추가·이동·삭제는 즉시 저장된다. 갤러리는 프로필 폼과 독립적이므로 프로필 미저장 텍스트를 덮어쓰지 않는다. 갤러리 작업 중에는 갤러리 버튼을 잠그고 창 닫기 시 확인을 요구한다. 강제 종료·디스크 부족·전원 차단 환경 및 실제 Windows는 미검증이다.
