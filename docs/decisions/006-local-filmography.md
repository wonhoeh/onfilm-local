# 로컬 필모그래피 정보 편집

기존 OnFilm의 편집 CSS와 작품 카드/입력 항목을 재사용한다. 초기 프로필 폼에는 추가하지 않는다. 프로필의 빈 상태 버튼 및 편집 메뉴에서 별도 화면으로 진입한다.

## 저장

- V5로 전용 작품 테이블과 단일 version 상태 행 추가. V1~V4 및 기존 사용자 데이터는 수정하지 않는다.
- GET/PUT `/api/filmography`. PUT은 전체 편집 결과와 읽었던 version을 제출한다.
- version 조건부 UPDATE로 변경권 확보 후 동일 트랜잭션에서 추가·수정·삭제·순서를 반영한다. 실패하면 version까지 롤백한다.
- 기존 ID는 유지하고 신규 UUID는 서버에서 생성한다. 알 수 없는 ID/중복 ID는 거부한다. 누락한 기존 ID는 삭제한다.
- 역할/장르는 제한된 짧은 List이며 VARCHAR 내 줄바꿈으로 구분한다. 역할은 enum 허용값만, 장르는 줄바꿈 금지·각 30자·최대 10개. 검색/공유 장르 사전이 필요해지면 별도 마이그레이션으로 정규화한다.
- 최대 50개, 제목 필수 200자, 연도 1888~2100, 런타임 1~1440분, 배역 100자. 배우 역할이 없으면 캐스팅/배역을 저장하지 않는다.

## 오류와 범위

- 일괄 저장이므로 편집 중 삭제/순서 변경은 저장 전까지 DB에 반영하지 않는다.
- 미저장 이동/종료 확인. 입력 오류는 수정 가능하게 유지한다. 충돌/통신 오류는 결과가 불명확하므로 재저장 차단 후 다시 읽기로 확인한다. 화면의 초안은 남기며 다시 읽기 전 폐기 여부를 묻는다.
- 프로필 조회 실패를 빈 작품 상태로 오인하지 않고 별도 재시도 버튼을 제공한다.
- 섬네일/트레일러/영상 업로드는 다음 단계. 원본 업로드 영역 위치에 미지원 안내를 표시하며 가짜 업로드 버튼을 만들지 않는다.
- 공개 설정/표준 장르 검색/드래그 정렬은 제외. 정렬은 명시적 위로·아래로 버튼.
- 영화 공유 카탈로그, 계정별 권한, Kafka를 도입하지 않는다. 기존 로컬 API 접근 필터를 그대로 사용한다.

## 검증

파일 H2 임시 디렉터리에서 생성·수정·정렬·삭제·재시작·오래된 버전·잘못된 ID·중복 ID·입력 제한 및 부분 쓰기 롤백을 테스트한다. 실제 사용자 DB는 사용하지 않는다.
