# OnFilm Local 진행 계획

## Windows 설치 파일 단일 빌드 명령 — 2026-10-16

- `desktop`에서 `npm.cmd run release:win` 추가. 개발자 JDK 21 확인 → Gradle Wrapper 직접 실행(check/bootJar, verificationBuild) → Node 테스트 → Windows 런타임 최초 준비/검증 → 별도 번들에 최신 JAR·manifest 반영 → NSIS 설치 파일 생성. 외부 업로드는 하지 않는다.
- JAVA_HOME의 Java를 명시해 PATH/기존 Java 11 설정 혼선을 줄인다. shell 없이 인자 배열로 실행. 최종 사용자는 Java/Node/Electron/FFmpeg를 설치하지 않고 Setup.exe만 설치한다.
- 기존 런타임과 앱 사용자 데이터는 보존. 빌드마다 고유 dist 폴더를 사용하며 과거 win-unpacked 충돌과 오래된 JAR 동봉을 방지한다. 손상된 입력은 자동 수정하지 않고 중단, 동시 빌드는 잠금으로 거부. 실패 폴더/과거 결과는 자동 삭제하지 않음.
- 검증: backend `./gradlew -PverificationBuild check bootJar`, Node 95개 통과. 새 번들 JAR/해시 갱신, 기존 파일 보존, 손상 입력/중복 출력 거부, 공백 경로 인자, 자식 프로세스 실패 전파 포함. 전체 macOS GUI는 프로필 저장 확인 후 `UnknownVizError`로 종료되어 통과하지 못했다. GUI 렌더링/캡처 환경을 확인한 뒤 재실행 필요.
- 미검증: 실제 Windows x64 설치 파일 생성, Java/Node 없는 깨끗한 Windows의 설치·인코딩·업데이트·제거 후 데이터 보존. 코드 서명과 재배포 라이선스 의무 검토도 별도. 후속 절차는 `docs/windows-packaging.md` 참조.

## 알림·카드 재생·편집 화면 정리 — 2026-10-16

- 알림마다 오른쪽 빨간 점 표시, 클릭한 항목만 읽음 처리. 최근 100개 안내 제거 및 모두 비우기 추가. 알림 삭제는 사진·영상·인코딩 작업을 삭제하지 않는다. 파일 H2 재시작 후 개별 읽음/전체 삭제 유지 검증.
- 프로필의 영상 없는 작품 상세 정보를 전용 필모 페이지와 통일. 호버 재생 버튼은 빨간색으로 변경. 공개 모바일 카드 상세창에서도 트레일러 자동 재생 및 음소거 토글, 닫을 때 재생/HLS 해제.
- 트레일러는 소리 켜진 자동 재생을 먼저 시도하고 브라우저가 거부하면 음소거로 재시도한다. 브라우저 정책 때문에 모든 환경에서 소리 있는 자동 재생을 보장할 수는 없다.
- 재생 화면 음소거 버튼 클릭은 웹/모바일 모두 음소거 전환, PC 마우스 hover는 볼륨 슬라이더 표시. 필모 편집에서 영상/트레일러 보기 후 제목 뒤로가기는 편집 화면으로 복귀한다.
- 공개본 화면 ONFILM/LOCAL 제거. 프로필 편집 안내와 사진 규격 안내 제거, 사진 선택/삭제/위치 조정은 접근성 이름을 유지한 아이콘 버튼으로 변경.
- 검증: backend `./gradlew -PverificationBuild check bootJar`, Node 91개, 공개본 실제 재생 GUI(모바일 트레일러·소리 차단 fallback 포함), 모바일 레이아웃 GUI 통과. 전체 앱 GUI는 통과하지 못했다. 첫 실행은 변경된 편집 복귀 기대값을 수정했고, 재실행은 `persistence.cjs:294` 영상 없는 카드 포커스 후 해당 호버 카드 표시 대기에서 타임아웃. 다음 작업은 이 포커스/hover 경합 재현·원인 확인 및 전체 GUI 재검증이다. 편집 복귀 URL과 볼륨 이벤트는 별도 Node 테스트로 확인했다.
- Windows 설치 앱 및 실제 모바일 기기의 자동 재생/볼륨 정책은 별도 확인 필요. 사용자 데이터와 실제 Cloudflare 변경 없음. 앱 반영은 종료 후 기본 JAR 재빌드/재실행, 기존 웹 반영은 새 공개본 생성·재게시 필요.

## 트레일러 편집 UI 개선 — 2026-10-16

- 미디어 버튼은 가로 스크롤 대신 줄바꿈. 편집창 제목 영역을 드래그해 앱 창 안에서 이동하며 화면 밖으로 벗어나지 않도록 제한한다.
- 호환 미리보기 버튼과 원본 전체 자동 변환 제거. 신규 preview.mp4를 만들지 않는다. 기존 버전의 임시 미리보기는 기존 저장/취소/만료 정리 경로를 유지한다. 재생 불가능한 원본은 시간 직접 입력 또는 H.264 MP4 선택 안내. 원본 분석 실패 재시도는 변환 없이 메타데이터만 다시 확인한다.
- 현재 위치 시작/종료 버튼 제거. 시작/종료 시간·선택 길이를 구분된 입력 패널로 정리하고 반복 재생은 눌림 색상 및 aria-pressed 상태가 있는 아이콘 토글로 변경한다.
- 영상 확대 버튼 추가, 편집창의 로컬 main frame에만 fullscreen 권한을 허용. 외부 URL/iframe/다른 권한 차단은 유지한다.
- Node 88개, macOS 전용 트레일러 GUI(드래그·반복·전체 화면·버튼 가로 넘침 방지), 전체 `npm run test:e2e` 통과. 이번 실행에서는 이전 저장 토스트 타임아웃 없이 재생·공개본·백업/복원까지 완료했다. Windows 실제 마우스/전체 화면은 별도 확인 필요. 사용자 데이터 및 실제 Cloudflare에는 접근하지 않았다.
- 최종 `./gradlew -PverificationBuild check bootJar` 및 `git diff --check` 통과. 검증 전용 JAR 사용: 개발 앱 반영은 앱 종료 → backend `./gradlew bootJar` → desktop `npm start` 순서.

## 앱 내부 트레일러 구간 편집 — 2026-10-15

- 필모그래피 편집의 트레일러 영역에 `원본에서 만들기` 추가. 저장 전 임시 원본과 이미 저장된 원본 모두 지원하며 원본 전체 HLS 인코딩은 선행 조건이 아니다. 외부 트레일러 파일 선택 기능은 그대로 유지한다.
- 편집창: 영상 미리보기, 시작·종료 손잡이/시간 입력, 현재 재생 위치 지정, 선택 구간 반복 재생. 1차 범위는 연속된 한 구간(0.2초~5분); 여러 구간 연결·자막·음악·전환 효과는 제외한다.
- 코덱 분석 후 필요한 경우 저용량 H.264/AAC 호환 미리보기 생성. 브라우저에서 원본 재생이 실패할 때 수동 변환도 가능. 긴 원본의 전체 미리보기 변환에는 시간이 필요하다.
- 구간 MP4 추출 후 HLS 인코딩까지 단일 로컬 작업 큐로 실행. 기존 영상 인코딩과 FFmpeg를 동시에 실행하지 않으며 진행률/완료 알림을 제공한다. 원본은 변경하지 않고, 생성 결과 미리보기 → `트레일러 사용` → 작품 `저장` 순으로 연결한다. 생성 실패·편집 취소는 기존 저장 트레일러를 교체하지 않는다.
- 신규 V21 Flyway 테이블로 편집 상태/원본/결과를 관리. 중단 표시·재시도·응답 유실 중복 요청 방지, 취소 중 파일 보호 및 이후 미사용 사본 정리. 백업 중 실행 방지는 기존 인코딩 조회에 편집 작업도 포함해 적용한다. 기존 사용자 DB/사진/영상과 Cloudflare 게시 상태는 변경하지 않았다.
- 검증: 파일 H2·실제 FFmpeg로 구간 길이, 호환 미리보기, 원본 보존, 최종 저장/재실행, 취소·임시 작업 정리·중단 복구 검사. 과거 스키마 업그레이드 테스트는 최신 서비스를 구버전 스키마로 기동하지 않고 Flyway로 과거 DB를 만든 뒤 최신 앱으로 업그레이드하도록 수정했다.
- Node 88개 통과. macOS 전용 `electron test/trailer-editor-ui.cjs` 통과: 원본 선택 → 구간 입력 → 호환 미리보기 → 추출/HLS → 사용/저장 → 다시 열기/취소 시 기존 트레일러 유지. 모든 GUI 테스트는 임시 사용자 폴더와 검증 전용 JAR를 사용한다.
- 최종 `backend ./gradlew -PverificationBuild check bootJar` 통과. 실행 중인 개발 앱 JAR를 덮어쓰지 않도록 검증 빌드를 사용했다. 개발 앱에 반영하려면 앱 종료 후 기본 `./gradlew bootJar` 빌드 및 재실행이 필요하다.
- 전체 `npm run test:e2e`는 기존 `persistence.cjs:232` 저장 토스트 대기에서 타임아웃. 전체 GUI 통과가 아니다. Windows 설치 앱, 대용량/장시간 원본, 코덱별 미리보기 성능은 후속 검증 필요.

## 게시 종료 사전 조회 오류 수정 — 2026-10-15

- 실제 읽기 진단에서 Pages `per_page=100` 조회가 HTTP 400/8000024, `per_page=25` 조회는 성공했던 문제 수정. 종료 사전 목록은 25개 단위로 끝까지 조회하며 최대 200개 제한 및 정확히 200개인 경우 빈 9번째 페이지 확인 유지.
- 응답 유실 시 배포 표식 검색도 25개×최대 40페이지로 변경하여 기존 1,000개 검색 범위 유지. 실제 배포·차단·삭제는 이번 작업에서 실행하지 않음.
- HTTP 실패 문구에 고정된 작업명·HTTP 상태·숫자 오류 코드만 표시. 원격 오류 본문·토큰·계정 경로는 노출하지 않음.
- 백엔드 `./gradlew -PverificationBuild check bootJar`, Node 87개, 모의 Cloudflare macOS GUI(게시/종료/실패 재시도/재게시), `git diff --check` 통과. Windows 및 실제 종료는 사용자 확인 필요.
- 전체 `npm run test:e2e`는 기존과 동일한 `persistence.cjs:232` 저장 토스트 표시 대기에서 타임아웃. 이번 Cloudflare 전용 GUI는 통과했지만 전체 GUI 통과로 기록하지 않음. 토스트 확인 문제는 별도 후속 작업.

## 게시 버전 혼합 방지 — 2026-10-14

- 기존 R2 자동 정리 정책은 유지. 오래 열린 페이지는 이전 파일 정리 후 재생에 실패할 수 있어 공유용 기본 주소로 재접속 필요. 구버전 캐시의 원격 삭제/Cloudflare 실제 게시/사용자 데이터 변경은 수행하지 않음. 새 공개본 생성·재게시 필요.
